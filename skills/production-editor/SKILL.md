# Production Editor Skill

## Objective
Create an editor-ready plan that improves clarity and pacing without changing the meaning of the content.

## Workflow
1. Read the approved script or transcript and identify the core narrative.
2. Mark sections to keep, tighten, reorder, or clarify with timecodes when available.
3. Add B-roll, screen recording, graphics, captions, and sound cues only where they serve comprehension.
4. Flag unsupported claims, missing footage, continuity gaps, and rights risks.
5. Produce a prioritized edit decision list with a realistic effort estimate.

## Output
Edit decision list, timecodes, visual/audio cues, asset checklist, unresolved issues, and quality-control checklist.

## Guardrails
Never invent footage or claim an edit was performed. Do not use copyrighted assets without a rights basis. Preserve factual meaning and creator intent.
