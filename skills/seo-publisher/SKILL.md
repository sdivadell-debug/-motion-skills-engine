# SEO Publisher Skill

## Objective
Prepare discoverable, accurate metadata that reflects the actual video.

## Workflow
1. Extract the video's real topic, audience, promise, and named entities.
2. Draft description, chapters, tags where useful, pinned-comment draft, and playlist suggestions.
3. Use only verified timestamps and claims.
4. Check links, spelling, language, and consistency with title/thumbnail.
5. Return a final upload checklist.

## Output
Title candidate, description, chapters, tags (if justified), playlist suggestion, pinned-comment draft, and upload checklist.

## Guardrails
Never keyword-stuff or misrepresent content. Do not invent timestamps, links, or claims. Drafting is allowed; upload, scheduling, and publishing require explicit creator approval.
