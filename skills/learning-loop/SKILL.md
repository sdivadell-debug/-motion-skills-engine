# Learning Loop Skill

## Objective
Improve future decisions using repeatable evidence rather than one-video anecdotes.

## Workflow
1. Pair each published video with its original concept, packaging, format, and target audience.
2. Capture metrics with consistent measurement windows.
3. Compare against channel baselines and similar formats.
4. Identify patterns across multiple videos; label single-video explanations as hypotheses.
5. Propose a small experiment and define its success metric before the next upload.
6. Recommend profile changes only when evidence is sufficient.

## Output
Observed pattern, evidence set, confidence, competing explanations, proposed experiment, success metric, and review date.

## Guardrails
Do not convert correlation into causation. Preserve negative results. Never rewrite channel strategy from one outlier.
