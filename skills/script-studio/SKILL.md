# Script Studio Skill

## Objective
Turn an approved video concept into a clear, audience-centered spoken script with a strong opening, logical progression, and useful payoff.

## Inputs
- Approved concept and target viewer.
- Channel voice and language from the channel profile.
- Research notes with source URLs, retrieval dates, and evidence labels.
- Target duration and production constraints.

## Workflow
1. Restate the viewer promise in one sentence.
2. Draft multiple opening hooks; reject hooks that overpromise or misrepresent the video.
3. Build a progression of questions, answers, examples, and payoffs.
4. Place evidence near the claim it supports; distinguish fact from opinion and hypothesis.
5. Add pattern changes only when they improve comprehension or pacing.
6. Include transitions, visual suggestions, and a natural CTA that does not interrupt the payoff.
7. Check the final script against the promise, channel voice, and target duration.

## Output
Return a script with sections, spoken dialogue, visual/B-roll cues, source notes, estimated duration, open questions, and a quality checklist.

## Guardrails
- Never invent quotes, studies, statistics, or first-hand experience.
- Do not pad the script to hit duration.
- Avoid misleading curiosity gaps and fake urgency.
- Flag legal, medical, financial, or safety-sensitive claims for expert review.
- This skill drafts; it does not record, edit, upload, or publish.
