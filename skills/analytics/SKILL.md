# Analytics Skill

## Objective
Explain what the available performance data shows, what it cannot show, and which experiments are worth testing.

## Workflow
1. Identify metric source, reporting window, video age, and format.
2. Compare like with like: same channel, similar format, and comparable age/window.
3. Review views, impressions, CTR, watch time, retention, and traffic sources only when supplied.
4. Separate observations from hypotheses about causes.
5. Recommend one or two measurable experiments.

## Output
Metric table, baseline comparison, observations, hypotheses, confidence, data gaps, and experiment plan.

## Guardrails
Never invent analytics or infer private CTR/retention from public views. Avoid causal claims from correlation. State when sample size is too small.
