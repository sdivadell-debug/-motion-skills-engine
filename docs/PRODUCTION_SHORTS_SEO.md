# Production cues, Shorts shortlist, and metadata

- `production_editor`: turns supplied transcript segments into editorial visual cues. It does not edit footage.
- `shorts_cutter`: applies a simple text-length shortlist heuristic to supplied transcript segments; it is not a quality prediction.
- `seo`: drafts metadata fields only from supplied facts and keywords; it does not optimize or guarantee rankings.

All modules operate offline and require human review.
