# Analytics, learning, community, and weekly planning

These offline modules operate on supplied data only.

- Analytics compares views to a median baseline; it does not infer causes.
- Learning loop stores observations, hypotheses, and next tests, clearly marked as hypotheses.
- Community module marks comments for review; it never posts or deletes comments.
- Weekly planner sorts user-provided tasks by priority within a capacity limit.

All outputs are drafts and require human review. No external actions are performed.
