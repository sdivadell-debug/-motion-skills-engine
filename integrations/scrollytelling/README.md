# Scroll-Driven Interactive Landing Pages / Scrollytelling

This integration adds an **industry-agnostic** skill for creating client-specific scroll-driven websites. It is not a car-only template and does not assume that every project needs 3D.

## Skill

Read `.claude/skills/scrollytelling/SKILL.md` before planning or building this type of site.

## What the skill covers

- Intake of the client's industry, audience, brand, assets, story, CTA, budget, and device requirements.
- Choosing the right technique per project: CSS scroll-driven animations, GSAP ScrollTrigger, Three.js / React Three Fiber, video sequences, SVG, Canvas, or 2D motion.
- Storyboard and scene planning.
- Responsive design, accessibility, reduced-motion support, performance, SEO, and QA.
- Commercial asset licensing, client privacy, and explicit approval gates before outreach, purchases, deployment, publishing, or delivery.

## Official documentation

- GSAP ScrollTrigger: https://gsap.com/docs/v3/Plugins/ScrollTrigger/
- Three.js: https://threejs.org/docs/
- React Three Fiber: https://r3f.docs.pmnd.rs/
- MDN CSS scroll-driven animations: https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_scroll-driven_animations

## Important

This is a Claude Code skill and project guidance, not a hosted website builder or a deployed runtime. The actual stack, hosting, dependencies, assets, and costs depend on each client's brief. 3D is optional; use it only when it serves the story and works within performance and budget constraints.
