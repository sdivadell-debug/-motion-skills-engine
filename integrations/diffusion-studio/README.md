# Diffusion Studio — AI-assisted video production

Primary editing tool for the freelance video-production workflow in this repository.

## Upstream

- Editor: https://github.com/diffusionstudio/editor
- Official site and downloads: https://diffusion.studio/
- License: MPL-2.0 (verify the current upstream LICENSE before redistributing modified source).
- Agent workflows: Claude Code, Codex, OpenCode, and Pi are documented upstream. The desktop app exposes editing tools to agents.

## What it can do

The editor is designed for human-and-agent video production. Its documented workflows include:
- Inspecting source footage and metadata; extracting frames and filmstrips.
- Reviewing audio waveforms and transcribing speech with timestamps.
- Editing clips, building animated scenes and motion graphics, adding captions, and rendering exports.
- Iterating between the agent-authored project code and the visual editor.

The editor itself is open source under MPL-2.0. The official site says the editor and agent editing workflows are free; AI generation, transcription, and model-powered media analysis can consume paid credits. Check current pricing and model terms before promising any feature or cost to a client.

## Recommended use in this project

1. Receive the client's brief and confirm deliverables, duration, aspect ratio, language, deadline, revisions, and usage rights.
2. Check the source footage and create a written edit plan before making changes.
3. Use the editor for the approved edit: pacing, B-roll, captions, motion graphics, sound design, and color work.
4. Inspect the rendered export and verify audio, captions, spelling, aspect ratio, black frames, and file integrity.
5. Present a review copy to the user. Deliver to the client only after the user's approval.

## Important limitations

- This is an editing tool, not a complete freelance marketplace, lead-generation CRM, payment processor, or autonomous agency.
- Agent-driven editing requires the supported desktop app and a compatible coding agent; a GitHub link alone does not install or activate it in Claude.ai chat.
- Desktop requirements and setup can change; follow the official upstream docs.
- Do not assume AI-generated media, stock assets, music, fonts, or voices are commercially cleared. Check each asset's license and the client's intended usage.
- Do not promise a specific result, delivery time, or AI feature until it has been tested with the actual footage and current account limits.

## Ethical and halal-oriented operating rules

This guide is designed to support permissible, honest creative services, but it is not a religious ruling or a guarantee that every project is halal. Review each client, brief, asset, and deliverable. Decline or ask for review when a project promotes gambling, betting, alcohol, pornography, fraud, interest-based lending, deceptive claims, or other clearly impermissible content. Do not use stolen footage, unlicensed music, impersonation, fake testimonials, misleading edits, or copyrighted material without permission.

## Security

- Never commit client footage, personal data, passwords, API keys, or private contracts to this repository.
- Keep client assets in separate, access-controlled project folders.
- Do not upload footage to third-party AI services without the client's informed permission and a check of the provider's data terms.
- Do not contact leads, send proposals, accept contracts, charge clients, or deliver externally without the user's explicit approval.
