# ChatGPT / OpenAI resources

This directory documents the official OpenAI resources relevant to this YouTube Agent Engine. It does **not** contain ChatGPT's proprietary application or model weights, and it does not install or extend the ChatGPT mobile/web app.

## Official resources

- [OpenAI GitHub organization](https://github.com/openai) — official public repositories.
- [OpenAI Cookbook](https://github.com/openai/openai-cookbook) — examples and guides for using OpenAI APIs.
- [OpenAI Python SDK](https://github.com/openai/openai-python) — official Python client for the OpenAI API.
- [OpenAI Agents SDK for Python](https://github.com/openai/openai-agents-python) — framework for building agent workflows.
- [Codex](https://github.com/openai/codex) — OpenAI's coding agent repository.

## Relevance to this repository

The project already has an optional OpenAI-compatible provider for generating draft scripts and ideas. See [AI provider setup](../../docs/AI_PROVIDER.md).

Use the API only when an authorized API key is configured in the local environment. Never commit API keys, passwords, session cookies, or other secrets. ChatGPT subscriptions and API billing are separate; a ChatGPT Free/Plus subscription should not be assumed to include API credits.

## What this entry is

This is a curated pointer to official, public source repositories and the existing integration point in this project. It is not a copy of ChatGPT, and it does not bypass product limits or provide free API usage.
