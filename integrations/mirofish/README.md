# MiroFish — Swarm Simulation Research

Official project: https://github.com/666ghj/MiroFish

## What it is

MiroFish is an open-source swarm-intelligence simulation engine. It takes source material (for example, a report, news item, policy draft, or idea brief), builds a simulated environment and creates AI agents with different profiles, memories, and behaviors. Those agents interact in the simulated world, and the system produces analysis or forecast-style reports that can be explored further.

This can be useful for:
- Exploring how different audience segments might react to a product idea, campaign, advertisement, or video concept.
- Stress-testing assumptions and identifying objections or overlooked perspectives.
- Generating scenario-based discussion and a structured report.

## Important limitations

- Simulated agents are AI-generated perspectives, not real people or a representative sample of the public.
- Outputs are scenarios and hypotheses, not verified predictions or evidence of actual audience behavior.
- Check important claims against real-world data and human feedback before making decisions.
- The project is licensed under AGPL-3.0; review the license and its obligations before modifying or deploying it, especially as a network service.
- Running simulations may require paid model/API usage and external service credentials. Do not assume it is free, and never commit API keys, tokens, or .env files to this repository.
